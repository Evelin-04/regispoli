1. Estructura del Archivo Excel

El Excel debe tener una fila de encabezados con exactamente estas columnas (sensible a mayúsculas y minúsculas). Puedes usar "SI" / "NO" en los campos lógicos.

2. Nomenclatura de Fotografías

El nombre de cada archivo de imagen (sin contar la extensión) DEBE ser idéntico al campo Numero de agente indicado en el Excel. El sistema cruzará esta información automáticamente.
